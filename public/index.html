SECURITY MODEL

Protect the platform. Understand the client boundary.

Code delivered to an untrusted Roblox client is accessible to that client. No web architecture can honestly guarantee that received Luau source cannot be inspected, copied, dumped, or reverse engineered.

This platform therefore focuses on authentication, authorization, scoped access, short-lived credentials, rate limiting, auditability, and keeping sensitive business logic server-side.
